# docs/images — 文档用的界面截图

这个目录只放**文档正文引用的界面截图**（PNG）。

## 红线：不要放含个人信息的截图

截图与标注前，请先把敏感信息遮掉或截掉，至少包括：

- 会话内容（用户与模型的对话正文）
- 工作区路径、项目名
- 用户名、主机名、账号
- token、密钥、内部地址

无法干净遮掉的内容，就不要截进这张图；宁可只截设置弹窗本身那一小块。

## 来源与做法

- **来源**：真实 DSH 界面的截图，不是示意图。主图摄于 DSH `0.1.6-alpha.2`：无头 Chrome 走 CDP 连接本地 `dsh web` 的调试端口、带上连接 cookie，打开设置并点开「压缩与自动续写」，再按设置弹窗的矩形裁切。整个过程只读，**没点保存、没改任何参数**。
- **做法**：裁切面板 → 在页面上叠一层合成画布（底图 + 彩色框 + 右侧图例）→ 1.5× 导出 PNG，**覆盖同名文件**即完成更新（README 里的引用路径不用动）。
- **数值说明**：图里的字段值是该 preset 的**现值**（两张比例带「已覆盖」标记），不是出厂默认；正文表格里写的才是默认值。这不算个人信息，但容易被误读，所以两份 README 都在图下点了这一句。
- **无个人信息**：图里没有会话内容、工作区路径、用户名、主机名、token、内部地址 —— 裁切范围就是设置弹窗（左栏 + 表单），会话侧栏与工作区列表都在框外。这也是上面那条红线的验收标准。
