# docs/images — 文档用的界面截图

这个目录只放**文档正文引用的界面截图**（PNG）。

## 红线：不要放含个人信息的截图

截图前请先把敏感信息遮掉或截掉，至少包括：

- 会话内容（用户与模型的对话正文）
- 工作区路径、项目名
- 用户名、主机名、账号
- token、密钥、内部地址

无法干净遮掉的内容，就不要截进这张图；宁可只截卡片本身那一小块。

## 计划中的两张图（文件名固定，请勿改名）

| 文件名 | 内容 |
|---|---|
| `settings-card-collapsed.png` | **设置 → 插件 → 可配置** 列表里的「压缩与自动续写」卡片 —— **收起态**（只占一行） |
| `settings-card-expanded.png` | 同一张卡片的 —— **展开态**（5 个字段、两个生效时机题注、下拉框） |

README 里的引用按这两个文件名拼路径，改名会导致裂图。

## 怎么截

1. Windows 按 `Win+Shift+S` 截取区域（只框住卡片本身，别把整个设置页截进来）。
2. 截完存成 **PNG**，放进本目录（`docs/images/`）。
3. 建议宽度 **1200px 左右**，保持文字清晰；不要把图压得太狠，卡片上的小字要能看清。

## 截好之后怎么接进 README

在 `README.md` 的 `### 在「设置」里改这些参数` 小节里，**字段表格之后**插入两行图片引用：

```markdown
![设置里的「压缩与自动续写」卡片（收起态）](docs/images/settings-card-collapsed.png)
![设置里的「压缩与自动续写」卡片（展开态）](docs/images/settings-card-expanded.png)
```

英文文档 `README.en.md` 用**同一条路径** `docs/images/...`，alt 文案改成英文即可。

**注意**：图片文件还不存在时**不要**提前插入引用 —— 会显示成裂图。等两张 PNG 都放进本目录后再加，
或者先只加已经截好的那一张。
