# docs/images — 文档用的界面截图

这个目录只放**文档正文引用的界面截图**（PNG）。

## 红线：不要放含个人信息的截图

截图与标注前，请先把敏感信息遮掉或截掉，至少包括：

- 会话内容（用户与模型的对话正文）
- 工作区路径、项目名
- 用户名、主机名、账号
- token、密钥、内部地址

无法干净遮掉的内容，就不要截进这张图；宁可只截卡片本身那一小块。

## 来源与做法

- **来源**：用户本人对 DSH「设置 → 插件」页的真实界面实拍，不是示意图。
- **做法**：截图 → 在图上画框并编号（①②③④⑤）→ 右侧加对应图例 → 存成 PNG，**覆盖同名文件**即完成更新（README 里的引用路径不用动）。
- **无个人信息**：图里没有会话内容、工作区路径、用户名、主机名、token —— 这也是上面那条红线的验收标准。

## 将来要新增别的截图

1. **命名**：`settings-<用途>.png`，全小写、连字符分隔，见名知意。
2. **插在哪**：放进 `README.md` / `README.en.md` 里对应那一节的**正文第一句之后**，写成
   `![alt 文案](docs/images/<文件名>.png)`；英文文档用同一条路径、alt 文案改英文。
3. **顺序**：PNG 先就位、再插引用 —— 图还没进本目录就提前写引用，读者看到的是裂图。
